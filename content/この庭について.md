# この庭について

このサイトは、Obsidianで考えていることを整理し、公開できる部分だけを育てていくためのデジタルガーデンです。

ブログのように完成品だけを並べるのではなく、途中の考えや更新中の情報も、状態を明示したうえで公開します。

## 公開方針

- 個人的な考察は、未完成のまま更新します。
- 文学賞などの変わりやすい情報は、主催者公式サイトを一次情報とします。
- 公開用リポジトリには、非公開Vaultの内容を丸ごとコピーしません。

## 技術構成

- 執筆: Obsidian
- 静的サイト生成: Quartz
- 公開: GitHub Pages
- ソース管理: GitHub
