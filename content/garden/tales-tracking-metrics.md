# TALES投稿作品のトラッキング指標（PV・読了率・反応）

公開したあと、何を見ればいいのか。PVだけでは足りないし、コメントだけでは偏る。記録する指標を先に決めておかないと、後から比べられない。

## 指標の定義

- **PV**：エピソードページの閲覧数。流入経路は分からないので、外部要因と切り離せない。
- **読了率**：TALESの管理画面で確認できる範囲。最後まで読まれたかの推定。
- **スキ**：気軽な反応。PVに対する比率で見る。
- **コメント**：内容のある反応。件数より、何に言及しているかを見る。
- **2話目遷移率**：1話のPVに対する2話のPV。連載の継続性を見る指標。
- **外部流入**：note記事、X、ガーデンからの流入。UTMは付けられないので、公開タイミングとの前後で推測する。

## 記録のタイミング

- 公開24時間
- 公開7日
- 公開30日

この3点だけ取る。毎日見ると、数字に振り回される。

## 記録の形式

```text
日付 / 話 / PV / 読了率 / スキ / コメント / 2話遷移
2026-10-29 / ep01 / - / - / - / - / -
```

公開直後はデータがない。まずは空欄で枠だけ作っておく。

## note記事・マガジン側の指標

記事はTALESへの導線であり、それ自体も読まれる。同じ3点（24時間・7日・30日）で記録する。

- **PV**：記事の閲覧数
- **スキ**：PVに対する比率で見る
- **リポスト数**：SNSプロモーション機能の拡散効果。告知ポストのリポスト数で見る
- **有料部分の購入**：単体300円とマガジン500円のどちらで買われたか。リポスト経由の0円購入は別枠で数える
- **TALESへの遷移**：記事内リンクのクリック数は取れないので、記事公開日とTALESのPV増の前後で推測する

```text
日付 / 記事PV / スキ / RP / 0円購入 / 有料購入(単体) / 購入(マガジン) / 備考
2026-10-31 / - / - / - / - / - / - / 公開3日
2026-11-04 / - / - / - / - / - / - / 公開7日
2026-11-27 / - / - / - / - / - / - / 公開30日
```

- SNSプロモーション機能で「リポストで0円」に設定している。0円購入は拡散の対価であり、売上ではない
- 仕様上リポストなしでも割引購入が成立する場合があるため、0円購入数≠リポスト数として扱う

## 注意

TALESの仕様変更で取れる指標が変わる可能性がある。指標を作品の評価と同一視しない。PVが少ないのは、作品が悪いのではなく、導線がないだけのことが多い。
