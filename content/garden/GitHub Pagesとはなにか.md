# GitHub Pagesとはなにか

GitHub Pagesは、GitHubリポジトリにある静的なWebサイトを公開する仕組みだ。HTMLやCSS、JavaScriptなどの生成物をGitHub Actionsからデプロイできる。

## 自分の使い方

Quartzで生成したサイトを、GitHub Actionsを使ってGitHub Pagesへ公開している。`main`へ変更をpushすると、ビルドとデプロイが実行される。独自ドメインとHTTPSも設定している。
